# NeuroForensics Ai

AI-Powered Processor & GPU Digital Forensics Platform

## Overview

NeuroForensics Ai is an AI-powered digital forensics platform
designed to acquire, preserve, correlate and analyze volatile
CPU and GPU evidence for cyber investigations.

## Architecture

MEMO Collector
        ↓
AIF Evidence Container
        ↓
MEMO Analyzer
        ↓
Evidence Ingestion
        ↓
CPU / GPU / Processes / Network / Windows Events
        ↓
Correlation
        ↓
Detection
        ↓
AI + Explainable AI
        ↓
Forensic Report

## Components

### MEMO Collector

Evidence acquisition component responsible for collecting
forensic evidence and producing AIF v1 evidence containers.

### MEMO Analyzer

Native desktop forensic analysis platform built with Rust,
egui/eframe and SQLite.
