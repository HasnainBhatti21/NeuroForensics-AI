# MEMO Collector

**NEUROFORENSICS AI** · *Volatile Evidence. Stronger Forensics.*

MEMO Collector is a portable Windows GUI forensic evidence acquisition tool.
It collects volatile and system-state evidence from a live Windows 10/11 x64
machine into a single hashed **AIF** evidence container, with a complete
chain-of-custody record and an acquisition report.

It is a single portable executable: **no installer, no runtime dependencies,
works offline from a USB drive.**

---

## What it does

1. **Launch** → privilege check (offers standard UAC elevation if needed).
2. **CREATE NEW CASE** → Case ID, Case Name, Investigator, Organization,
   Evidence Description, Notes, optional Reference Number.
3. **Choose destination folder** for the evidence case.
4. **Select acquisition modules** (10 collectors; SELECT ALL /
   SELECT RECOMMENDED / CLEAR ALL). Optional clearly-labelled DEMO MODE.
5. **START ACQUISITION** → live progress per module and artifact,
   PAUSE / RESUME / CANCEL with partial-case preservation.
6. **Every artifact is hashed with SHA-256 during acquisition.**
7. **Package** `CASE-XXXX.AIF` + `.AIF.sha256` sidecar + `.custody.json`
   + `_acquisition_report.html` + `.acquisition.log`.
8. **VERIFY AIF** any time: Expected vs Calculated container hash (✓/✗)
   plus deep per-artifact verification against the manifest.

## Acquisition modules

| Module | Scope |
| --- | --- |
| System Metadata | Host identity, OS, firmware, disks, environment |
| CPU / System | Processor metadata and topology (register state explicitly NOT AVAILABLE) |
| Memory (artifact mode) | Memory statistics + bounded process region maps; raw physical RAM image NOT AVAILABLE (never faked) |
| GPU | Adapter metadata, driver info, compute stack; VRAM raw acquisition NOT AVAILABLE (never faked) |
| Processes | Process list/tree, loaded modules, handles, threads, integrity level |
| Network | Passive only: adapters, connections (netstat), routes, ARP, DNS |
| Windows Events | System/Application/Security/Sysmon (only when present) via Get-WinEvent/wevtutil |
| Persistence | Run keys, startup folders, services, scheduled tasks, WMI subscriptions (read-only) |
| Registry | Targeted artifacts: identity, installed software, USB history, network profiles |
| Hashes | SHA-256 of running process executables (bounded) |

## Prerequisites

- Windows 10/11 x64 (target platform).
- Administrator rights recommended: some sources (process memory regions,
  Security log, some registry keys) require elevation. The app runs without
  elevation and records honest NOT AVAILABLE / access-denied notes instead.

## Building from source

Prerequisites: Rust (stable, MSVC toolchain) and the Visual Studio C++
build tools (linker + Windows SDK).

```powershell
cargo build --release
```

Output: `target/release/MEMOCollector.exe` — a single portable binary.
Copy it anywhere (USB stick included) and run it.

## Usage

```
MEMOCollector.exe
```

- **Dashboard** shows system status, session privilege level, quick actions.
- **New Case** walks through case details, destination, module selection.
- **Acquisition** shows live progress and the completion summary with
  OPEN CASE LOCATION / VIEW MANIFEST / VERIFY INTEGRITY /
  CREATE ACQUISITION REPORT / CLOSE CASE.
- **Integrity** verifies any AIF against its sidecar hash or a custody record.

## Demo mode

DEMO MODE generates **SYNTHETIC DEMONSTRATION DATA** for workflow
demonstrations and training. Every demo artifact is flagged
`synthetic: true` in the manifest and carries the banner
`SYNTHETIC DEMONSTRATION DATA - NOT REAL EVIDENCE`. Production mode never
mixes synthetic data into real evidence.

## Integrity model

- Every artifact is streamed through SHA-256 at acquisition time.
- Artifact hashes live in `manifest.json` inside the container.
- A container cannot contain its own hash; the container hash is recorded
  externally in the `.AIF.sha256` sidecar and the `.custody.json` record.
- VERIFY AIF recomputes the container hash and re-hashes every artifact.
- One module failing never terminates the acquisition: failures are logged
  as warnings/skips and the run continues (status `COMPLETED_WITH_FAILURES`
  or `PARTIAL ACQUISITION` when cancelled).

## Limitations (by design, stated honestly)

- No raw physical memory (RAM) imaging; no VRAM capture; no CPU register
  state; no SAM hive extraction. When a source is unavailable the tool
  records an explicit NOT AVAILABLE statement — it **never fabricates
  evidence**.
- Network acquisition is passive only (no packet injection or interception).
- The tool performs **no analysis** and draws **no forensic conclusions**;
  interpretation is the examiner's job.
- Integrity metadata generated by MEMO Collector is not a legal
  certification.
